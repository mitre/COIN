# COIN

Conversational Interoperability (COIN) describes an approach to healthcare
interoperability in which AI agents help participants exchange and interpret
information and coordinate workflows.

This proposal sets out a framework for putting COIN into practice through shared
specifications and supporting resources.

## Build the documentation site

Optionally, install [Hugo](https://gohugo.io/installation/) and build
the documentation site:

```sh
hugo --minify
```

The generated site is written to `public/`.
